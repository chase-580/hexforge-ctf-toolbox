CONTACT & CORRECTIONS

联系我们

为了让问题可追踪，目前统一通过 GitHub Issues 接收反馈。

工具故障

请说明工具名称、输入的非敏感示例、预期结果、实际结果、浏览器版本以及复现步骤。不要提交真实凭据、Flag、个人信息或未公开题目附件。

内容纠错

如果教程中的概念、示例或链接不准确，请附上页面地址和具体段落。能够提供标准文档或可复现样例会帮助我们更快核对。

功能建议

请描述你的 CTF 场景、当前操作流程和最耗时的步骤。我们优先考虑能够在浏览器本地完成、用途明确且可安全演示的功能。

提交入口：
在 GitHub 创建 Issue，或查看已有问题。

安全问题

请不要在公开 Issue 中发布可直接利用的漏洞细节、访问令牌或个人数据。可以先创建一个不含敏感细节的问题，说明需要私下沟通；维护者确认渠道后再提供完整信息。

回复说明

这是独立维护项目，无法承诺固定响应时间。与工具正确性、隐私或站点安全相关的问题会被优先处理。
