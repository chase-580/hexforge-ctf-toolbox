PRIVACY NOTES

Privacy notes

Last updated: September 17, 2026

Tool input

Hexforge processes text and selected files in your current browser by default. The MVP does not upload Base64, URL, Hex, JWT, regex, hash, or file contents to a Hexforge server.

Traffic analytics

The site uses Cloudflare Web Analytics to understand page views, traffic trends, and basic performance. It is used to improve the tool directory and page structure, not to read tool input. See Cloudflare's official documentation and privacy policy for its processing details.

Local history

Recent operations, favorites, recently visited tools, toolchain step settings, challenge workspace content, and success/error counts that contain no input are stored in localStorage. Challenge attachments and screenshots are stored in IndexedDB in the current browser. A challenge workspace may include names, categories, tags, notes, flags, tool results, and files that you explicitly save; this content is not uploaded to a Hexforge server. Toolchain input and results are stored only after you select “Save to challenge.” Exporting a workspace writes this challenge data and its attachments to a JSON backup file downloaded to your device. Clearing site data removes these records.

Third-party services

The site is hosted on Cloudflare Pages and its source is hosted on GitHub. If advertising, accounts, or payments are added later, this page will be updated with the relevant services and data practices.

Contact

If you find an issue with a tool or this privacy note, please open an Issue in the project repository.
