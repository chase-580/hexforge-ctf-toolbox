PRIVACY NOTES

Privacy notes

Last updated: September 17, 2026

Tool input

Hexforge's basic tools process input text in your current browser by default. The MVP does not upload Base64, URL, Hex, JWT, hash, or text-statistics input to a Hexforge server.

Traffic analytics

The site uses Cloudflare Web Analytics to understand page views, traffic trends, and basic performance. It is used to improve the tool directory and page structure, not to read tool input. See Cloudflare's official documentation and privacy policy for its processing details.

Local history

The recent-use list on the workspace is stored in your browser's localStorage to restore recent tool operations. Clearing site data removes those records.

Third-party services

The site is hosted on Cloudflare Pages and its source is hosted on GitHub. If advertising, accounts, or payments are added later, this page will be updated with the relevant services and data practices.

Contact

If you find an issue with a tool or this privacy note, please open an Issue in the project repository.
