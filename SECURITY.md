# Security Policy

## Reporting a vulnerability

Please report security issues privately through [GitHub Security Advisories](https://github.com/chase-580/hexforge-ctf-toolbox/security/advisories/new). Do not open a public issue for an unpatched vulnerability.

Include the affected route or file, reproduction steps, browser version, expected behavior, and observed impact. Do not include real credentials, session tokens, private challenge data, or personal information.

## Scope

Reports about unintended data transmission, unsafe file handling, cross-site scripting, storage isolation, or misleading security claims are in scope. Tool results are educational aids and should be independently verified before they are used as evidence.
