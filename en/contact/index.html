CONTACT & CORRECTIONS

Contact

Feedback is tracked through GitHub Issues.

Tool problems

Include the tool name, a non-sensitive sample, expected and actual results, browser version, and reproduction steps. Do not post credentials, flags, personal data, or private challenge files.

Corrections

For an inaccurate concept, example, or link, include the page URL and exact section. A standards document or reproducible sample helps us verify the correction.

Feature proposals

Describe the CTF scenario, your current workflow, and the expensive step. We prioritize focused features that can run locally and be demonstrated safely.

Submit feedback:
Create a GitHub Issue or review existing issues.

Security reports

Do not publish directly exploitable details, tokens, or personal data in a public issue. Open a minimal issue without sensitive detail to request a private coordination channel.

Response time

This is independently maintained, so no fixed response time is promised. Correctness, privacy, and site security issues receive priority.
